# Online Payment Fraud Detection Using ML

## About the Project
This project is an Online Payment Fraud Detection System that uses Machine Learning and Deep Learning to identify suspicious payment transactions in real time.

It analyzes transaction details and user behavior to generate a risk score and decide whether a transaction should be allowed, verified, or reviewed.
